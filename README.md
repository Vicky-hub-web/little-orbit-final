# Little Orbit — Baby Safety Pillow

React + Vite ecommerce-style landing page for a baby safety pillow brand.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## GitHub Pages

This project is configured for the repository URL:
`https://vicky-hub.github.io/Little-orbit/`

The GitHub Actions workflow in `.github/workflows/deploy.yml` builds the Vite app and deploys `dist` to GitHub Pages.
